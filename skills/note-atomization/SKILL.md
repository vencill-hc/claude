# Note Atomization

Transform any content into a network of atomic, bidirectionally linked evergreen notes.

## Workflow

1. **Check config** - Look for `.claude-skills.yaml` in working directory or parents for `note-atomization.output`
2. **Identify source** - Read content to atomize. Ask if unclear.
3. **Set output** - Use config path, ask user, or fallback to `~/Documents/obsidian/claude-code/atomic-notes/`
4. **Extract key ideas** - Identify 5-15 atomic concepts worth remembering in 5 years
5. **Create notes** - Write each with proper frontmatter, inline links, and personal relevance
6. **Verify links** - Ensure all `[[links]]` reference notes that exist or will be created
7. **Offer ankification** - Ask: "Would you like Anki flashcards from these notes?"

## Core Principles (Andy Matuschak)

> "Evergreen notes are written to evolve and accumulate over time."

1. **Atomic** - One idea per note, fully developed
2. **Concept-oriented** - Organized by idea, not source
3. **Densely linked** - Connected via bidirectional links
4. **Associative** - Networks over hierarchies
5. **Personal voice** - Your words, for yourself

## The Title Test

Titles must be **complete thoughts**, not topic labels:

| Bad (Topic) | Good (Atomic) |
|-------------|---------------|
| Spaced Repetition | Retrieval practice strengthens memory more than re-exposure |
| Cognitive Load | Working memory has strict capacity limits that constrain learning |
| Note-taking | Most note-taking fails because it optimizes for capture, not understanding |

## Inline Linking

**Weave links into prose**, not just in "Related" sections:

```markdown
# Instead of:
"This relates to [[Planning prevents rework]]"

# Write:
"This is why [[Planning prevents rework|planning upfront]] saves time."
```

**Syntax:**
- `[[Note Title]]` - when title reads naturally
- `[[Note Title|display text]]` - when you need different phrasing

Link aggressively. Non-obvious connections are more valuable than obvious ones.

## Output Format

```markdown
---
created: {{date}}
updated: {{date}}
author: claude
source: "{{original source}}"
tags:
  - topic/subtopic
  - type/concept
  - status/evergreen
aliases:
  - alternative phrasings
cssclasses:
  - atomic-note
---

# [Complete Thought as Title]

[Single idea developed in 2-5 paragraphs. Weave [[Related Note|inline links]] naturally into prose.]

## Why This Matters

[Personal relevance. Why do YOU care? How does this connect to [[things you know]]?]

## See Also

[Optional. For connections that don't fit naturally inline.]

---
*Generated by Claude via note-atomization skill*
```

**Filename:** `{{Complete thought title}}.md`

## Quality Check

- [ ] Title is complete thought (not topic label)
- [ ] One idea per note
- [ ] Written in your own words
- [ ] Understandable without source
- [ ] 2-3+ inline links woven into prose
- [ ] Personal relevance stated

## Config

```yaml
note-atomization:
  output: ./atomic-notes/  # relative to config file
```
